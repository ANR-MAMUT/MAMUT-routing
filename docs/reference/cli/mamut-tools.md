# `mamut-tools` (MAMUT-routing-tools)

The local generation and solving suite of [MAMUT-routing-tools](https://github.com/ANR-MAMUT/MAMUT-routing-tools):
OpenStreetMap city acquisition, the road-graph engine, per-instance generation (CVRP, VRPTW and the
time-dependent twins), converters, BKS route geometry, solving, and the local workbench GUI.

```bash
uvx --from mamut-routing-tools mamut-tools --help   # no install needed
```
