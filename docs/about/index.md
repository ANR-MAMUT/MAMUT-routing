# About

MAMUT-routing is developed within the [ANR MAMUT project](https://anr.fr/Project-ANR-22-CE22-0016)
(ANR-22-CE22-0016), an academic research project on combinatorial optimization for logistics and transportation.

- [Authors](authors.md): authorship, supervision, contributors.
- [Funding](funding.md).
- [Related projects](related-projects.md): KAYROS, PyVRP, VRPLIB, CVRPLIB, and the benchmark sources.
- [Legal mentions](legal-mentions.md).
- [Citing](../user-guide/citing.md) and licenses.

The code is MIT; the data carries family-specific licenses (see each [family page](../benchmarks/families/index.md)
and the repository `NOTICE`). The repositories are archived by [Software Heritage](https://www.softwareheritage.org/).
